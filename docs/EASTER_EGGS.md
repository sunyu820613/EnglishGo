# EASTER_EGGS — 彩蛋机制

版本：1.0 ｜ 关联：[THEME_SYSTEM](THEME_SYSTEM.md) · [REWARD_SYSTEM](REWARD_SYSTEM.md)

## 1. 全局规则

- 每主题 ≥5 个低干扰彩蛋；全部为纯本地、无广告、无外链、无付费
- 彩蛋位于 decoration/character 层，**永不遮挡学习按钮**、不打断课程语音（彩蛋音效音量 -6dB）
- 彩蛋不产生学习进度要求；错过无任何损失
- 通用彩蛋（全主题）：连点主角色 5 次 → 隐藏动作；完成 A/B/C → 迷你故事；完成 A–Z → 主题音乐会

## 2. 各主题彩蛋清单

### starlight 星际探索站
1. 连点宇航狐狸 5 次 → 头盔起雾又擦净的滑稽动作
2. 地图上随机出现的小行星，点击 → 打转并露出躲藏的外星小朋友
3. 首页夜空按顺序点亮 3 颗指定星 → 星座连线成动物图案
4. 完成 S 字母后 → 首页出现流星雨背景事件
5. 收集 Sun+Star+Moon 贴纸 → 解锁狐狸与星星合影收藏卡

### dino 恐龙自然博物馆
1. 连点三角龙 5 次 → 开心打滚
2. 课程场景角落偶现半埋化石，点击 → 刷子扫出完整化石入收藏
3. 按顺序点击 蕨类→岩石→木牌 → 恐龙脚印一路亮起
4. 完成 D/E/F 后 → 展厅里的蛋出现裂纹，完成更多字母逐步孵化出小翼龙
5. 收集齐动物类单词贴纸（Cat/Dog/Bear…里程碑） → 动物合影收藏卡

### robot 未来机器人实验室
1. 连点小机器人 5 次 → 天线弹出彩色小旗
2. 地图传送带上偶现零件箱，点击 → 收集齿轮，集 5 个组装出迷你机械宠物
3. 按 红→蓝→橙 顺序按下场景按钮 → 实验室灯光秀
4. 完成 R 字母后 → 首页出现会跟随点击的迷你无人机
5. Robot 贴纸 + 3 星 R → 机器人朋友合影收藏卡

### moonGarden 月光魔法花园
1. 连点月兔 5 次 → 竖耳转圈撒月尘
2. 场景中含苞花朵点击 → 开花并飞出萤火虫（每晚样式随机）
3. 按顺序点 蘑菇→池塘→花 → 蘑菇发光小径亮起
4. 完成 M 字母后 → 首页月相开始随学习进度变化（新月→满月）
5. Moon+Owl+Rabbit 贴纸 → 月夜合影收藏卡

### balletCastle 云端芭蕾城堡
1. 连点小天鹅 5 次 → 旋转一周并鞠躬谢幕
2. 场景中云朵点击 → 变成云朵小动物飘过
3. 按顺序点 丝带→音乐盒→幕布 → 音乐盒开启播放八音盒旋律
4. 完成 B/C/D 后 → 舞台幕布后出现秘密小舞台入口（纯观赏动画）
5. Swan 相关（Whale/Watch 里程碑）→ 天鹅湖谢幕合影收藏卡

### dessert 甜点艺术工坊
1. 连点猫咪烘焙师 5 次 → 甩面团抛接
2. 烤箱偶尔“叮”一声，点击 → 会跳舞的饼干出炉跳一段
3. 按顺序点 奶油→草莓→蛋糕坯 → 组装出神秘蛋糕（样式轮换）
4. 完成 C 字母后 → 展示柜新增蛋糕，随进度越摆越满
5. Ice cream+Orange+Grapes 贴纸 → 甜品派对合影收藏卡

## 3. 实现要点

- 彩蛋状态存本地 progress JSON（`easterEggs: {found: [...]}`），家长区可见发现数量
- 顺序点击类彩蛋无失败反馈：顺序错了就静默重置
- `ReducedMotion` 时彩蛋动画简化为淡入淡出，不禁用（保持乐趣）
