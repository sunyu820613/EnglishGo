# PRIVACY_AND_KIDS_POLICY — 儿童隐私与商店政策自查

版本：1.0 ｜ 状态：内部自查文档，**不构成法律意见**，发布前需正式合规审查。

## 1. 数据实践声明（v1）

| 项 | 实践 |
|---|---|
| 收集的数据 | **零收集**。学习进度/设置仅存本机（shared_preferences），永不上传 |
| 网络请求 | 核心功能零网络请求；App 不申请 INTERNET 之外权限（若打包无需网络则不声明） |
| 账户/登录 | 无 |
| 广告/行为广告/广告 ID | 无，不读取 AAID/IDFA |
| 第三方 SDK | 无统计/崩溃上报 SDK（v1）；依赖仅限 UI/存储/音频类，逐一审计（DEPENDENCY_AUDIT） |
| 姓名/生日/位置/联系人 | 不收集、不申请权限 |
| 聊天/UGC/上传 | 无 |
| 外部链接 | 仅隐私政策页，置于家长门之后 |
| 数据删除 | 家长区“重置进度”即完全删除；卸载即全部清除 |

## 2. 分店/法规自查清单

### Apple Kids Category
- [x] 无第三方广告、无行为分析
- [x] 外链/购买机会置于家长门后（v1 无购买）
- [x] 不收集个人信息；无社交功能
- [ ] 提交时勾选 Kids Category 并附隐私政策 URL（发布期）

### Google Play Families Policy
- [x] 目标受众：5 岁及以下/混合 → 走 Families 自查问卷
- [x] 无广告 SDK；依赖需符合 Families Self-Certified Ads SDK 要求（v1 无）
- [x] 不请求位置/联系人等敏感权限
- [ ] Data Safety 表单填“无数据收集/共享”（发布期）

### COPPA（美国）
- [x] 不收集 13 岁以下儿童个人信息（零收集策略），无需可验证家长同意流程
- [x] 无持久标识符用于广告/画像

### GDPR-K（欧盟）
- [x] 无个人数据处理 → 不触发同意年龄门槛问题
- [x] 若未来加入分析，须先做 DPIA 并取得家长同意（记录为未来约束）

### 日本（个人情報保護法 + 消费者保护）
- [x] 无个人信息收集；无课金 → 不触发资金决済法/景表法抽选规制
- [x] 无诱导性“おねだり”设计（无内购）

## 3. 隐私政策页要点（家长门后展示）

- 用家长可读的语言说明：所有数据仅存设备本地、内容离线、无广告、无收集、重置/卸载即删除
- 提供开发者联系方式（发布期补充）
- 多语言：中/英/日

## 4. 工程守则

- 任何新依赖引入前检查其是否包含遥测（DEPENDENCY_AUDIT 流程）
- Debug 日志不得包含任何可识别信息；Release 关闭 verbose 日志
- 构建产物审计：确认无广告/统计 SDK 混入（Phase 5 检查项）
