# REWARD_SYSTEM — 奖励系统

版本：1.0 ｜ 关联：[LEARNING_MODEL](LEARNING_MODEL.md) §5 · [THEME_SYSTEM](THEME_SYSTEM.md) · [EASTER_EGGS](EASTER_EGGS.md)

## 1. 原则

鼓励而不施压：只加不减、只解锁不惩罚、无时间压力、无比较。

## 2. 星星（每字母最多 3 颗）

| 星 | 条件 | 说明 |
|---|---|---|
| ★1 | 听完两个单词发音 | 被动完成即可 |
| ★2 | 完成听音选图 | 错几次都算完成 |
| ★3 | 完成字母匹配或描线任一 | 描线可跳过不影响 |

重学可补星；星星永不清零、不过期。

## 3. 奖励内容

| 奖励 | 触发 | 存放 |
|---|---|---|
| 单词贴纸 ×52 | 首次听完该单词发音 | 收藏册（贴纸页） |
| 字母徽章 ×26 | 该字母达 3 星 | 收藏册（徽章页） |
| 主题收藏品（每主题 1 册） | 星星累计里程碑（5/10/15…颗） | 收藏册（主题页），六主题独立奖励箱样式 |
| 角色表情/动作 | 里程碑解锁 | 角色待机动作池扩充 |
| 场景装饰品 | 里程碑解锁 | 首页场景逐渐丰富 |
| 迷你故事 | 完成 A/B/C、D/E/F… 每 3 字母一段 | 收藏册（故事页） |
| 字母音乐会 | A–Z 全部 ≥1 星 | 首页特殊入口 + 完成庆典 |

## 4. 连续学习（成长花园/星星轨迹）

- 家长区展示为“成长记录”，儿童侧表现为场景装饰自然生长（如星轨变长、花园开花）
- 中断后：不清零、不出现枯萎/哭脸/警告，回来时角色只说 “Good to see you!”

## 5. 禁止清单（实现与审查硬性项）

虚拟货币、抽卡/随机付费奖励、倒计时、排行榜、与其他儿童比较、中断惩罚、每日签到强制、诱导购买、能量/体力限制。

## 6. 结算体验（课程步骤 10）

星星逐颗飞入 `StarMeter`（`motion.celebrate`）→ 新贴纸从插画飞入收藏册图标 → 角色庆祝动作 + 主题庆祝动画 → 温和收尾语音（"Wonderful! See you next time!"）。全程 5–8 秒，可点击跳过。
