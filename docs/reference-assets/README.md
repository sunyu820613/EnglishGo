# Reference assets — not shipped in the app

These 5 files are **reference material only**, used to check proportions and
anatomical accuracy while redrawing the parametric side-profile mouth rig.
They are not imported, bundled, or shipped by the app.

## Source

Sagittal-section vocal tract diagrams, originally created by Richard Wright
and Dan McCloy (2011) for Linguistics 450/550 at the University of
Washington, released under **CC0 1.0** (public domain) by Dan McCloy on
GitHub (2023-06-13).

- Repository: https://github.com/drammock/phonetics-teaching-assets
- License: CC0 1.0 Universal — https://github.com/drammock/phonetics-teaching-assets/blob/main/LICENSE
- Files used (from `midsaggital_articulations/`):
  - `theta.svg` — `consonants/svg/θ.svg` (/θ/)
  - `ng.svg` — `consonants/svg/ŋ.svg` (/ŋ/)
  - `r_retroflex.svg` — `consonants/svg/r_retroflex.svg` (/r/, American retroflex variant)
  - `ae.svg` — `vowels/svg/æ.svg` (/æ/)
  - `i.svg` — `vowels/svg/i.svg` (/iː/, same target articulation)

CC0 permits direct reuse without attribution, but these are kept as
reference-only (not redistributed as app assets) because the app's rig is a
simplified, stylized, animatable redraw rather than these exact illustrations.
